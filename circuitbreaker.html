CircuitBreaker v2.5-VANGUARD

Chunk-based event filter engine to isolate and defuse lag machines without interrupting player gameplay. Features interactive GUI controls (/cb gui) and redstone loop throttling.

Download v2.5-VANGUARD GitHub Source

In-Game Commands & Anti-Lag GUI

/cb gui

Opens the interactive Anti-Lag GUI displaying laggy chunks, active redstone loops, and TPS impact.

/cb status

Displays live server TPS, MSPT metrics, and active throttled chunks.

/cb freeze <chunk>

Manually freezes physics and redstone updates in a targeted chunk.

/cb reload

Reloads CircuitBreaker thresholds and chunk monitoring configs instantly.
