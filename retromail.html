📧 DOUBLE OPT-IN SMTP EMAIL VERIFICATION

RetroMail v1.0.7-DEADEYE

Secure double-opt-in SMTP gateway integration. Verifies player emails in-game, triggers verification rewards, and supports mass email announcements (/mass-email).

Download v1.0.7-DEADEYE GitHub Source

In-Game Commands & Usage

/email <address>

Dispatches a 6-digit confirmation PIN to the player's email address via SMTP.

/email verify <code>

Confirms email ownership and triggers automatic in-game rewards.

/mass-email <perm> <subject> <msg>

Sends broadcast email announcements to verified player groups asynchronously.

/email resend

Requests a new verification code if the previous code expired.
