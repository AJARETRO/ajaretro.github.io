Native 60 FPS Smooth Movement

Minecraft server ticks run at 20 TPS, but SuperBoard-RETRO triggers Minecraft 1.19.4+ Display Entity Client Interpolation. By setting setInterpolationDuration(2) and setTeleportDuration(2), pieces slide smoothly across boards at the player's native monitor refresh rate (60 FPS / 144 FPS) with zero server lag!

Sub-Tick Frame Rendering
Linear keyframe translation between server ticks.
Zero Network Bloat
Interpolation logic executes on client GPU.
// DisplayBoardRenderer.java - 60 FPS Movement API
public static void enableSmooth60FpsMovement(BlockDisplay display, int ticks) {
display.setInterpolationDuration(ticks); // 2 ticks = 60 FPS interpolation
display.setTeleportDuration(ticks); // Smooth position sliding
display.setInterpolationDelay(0); // Immediate transition
}

DMCA Protection & Server Rebranding

Fully Customizable Game Display Names

To avoid trademark conflicts (such as UNO or Tetris) and allow server networks to rebrand game modes to fit custom server lore, SuperBoard-RETRO lets developers change any game title directly in config.yml!

# config.yml
game-display-names:
COLOR_MATCH: "Color Match Royale"
TETRIS: "Block Stack Arcade"
WORDLE: "Word Guess"
CHESS: "Grandmaster Chess"

Why Rebranding Matters

Default game mode keys use neutral names like Color Match instead of trademarked brand names. Developers can hot-reload these names anytime with /superboard reload.
