Minecraft Plugin Pricing: How Free vs. Commercial Licenses Work

Discover the structure of our software pricing model. Learn what is included in the Community Edition and what the Commercial License unlocks.

Monetizing software in the Minecraft ecosystem is a delicate balance. On one side, developers need to cover hosting costs and devote hundreds of hours to writing optimized code. On the other side, server owners need accessible tools to grow their networks.

To address both needs, we utilize a **split-tier pricing model** (Free Standalone vs. Paid Commercial) across our premium plugins like RetroMail and CircuitBreaker. Let's look at exactly how both tiers function and how to choose the right one for your network.

1. RetroMail Community Edition (Free)

The **RetroMail Community Edition** is published for free on Modrinth and SpigotMC. It is designed to help small, single-server setups and hobbyist networks verify player emails securely without upfront costs.

  • ⚙️ Standalone Core Verification: Includes full double-opt-in SMTP email verification. Players type their email in-game, receive an activation code in their inbox, and unlock reward commands upon verification.
  • 💾 Local Storage & Config: Verification records and player data are stored locally in a single SQLite database, and configurations are managed through standard local `.yml` files.
  • 👥 Community Support: Support is handled through community Discord channels and public GitHub issue boards.

The Community Edition is fully functional, free of advertisements, and will remain free for server owners forever.

2. RetroMail Commercial License (Paid)

The **RetroMail Commercial License** is built specifically for scaling Minecraft networks (BungeeCord/Velocity setups), commercial networks, and server owners who want full automation, visual styling tools, and direct priority support.

Multi-Server Network Sync

Paid commercial licenses unlock Velocity and BungeeCord proxy integrations. Player verification queues, reward commands, and sync states are coordinated globally via Redis and MySQL databases, ensuring players don't have to re-verify when switching server nodes.

Full-Stack Web Dashboard

Access to the responsive administration web portal (front-end). Admins can view real-time player verification analytics, customize newsletter themes visually in a browser editor, manage licenses, and send mass emails using a secure web composer interface.

  • 🔑 Automated License Verification: Paid installations link securely to our centralized licensing server using HMAC-SHA256 signature verification.
  • 📞 Dedicated Developer Retainer: Commercial clients receive direct developer support with guaranteed SLA response times to handle custom patch requests, API integrations, and database migrations.

Conclusion

Our pricing model is built to scale *with* your server. As your player base grows and your setup transitions from a single server to a network cluster, you can transition from the free standalone tier to the commercial license to unlock multi-server sync, web panels, and dedicated support.
