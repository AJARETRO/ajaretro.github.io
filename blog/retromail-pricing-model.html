RetroMail Pricing Model: How Free vs. Commercial Editions Work

Discover the structure of our software pricing model. Learn about the free Community Edition with full multi-server sync, and what the Commercial License unlocks.

Monetizing software in the Minecraft ecosystem is a delicate balance. On one side, developers need to cover hosting costs and devote hundreds of hours to writing optimized code. On the other side, server owners need accessible tools to grow their networks.

To address both needs, we utilize a **split-tier pricing model** (Free Standalone vs. Paid Commercial) for **RetroMail**. Let's look at exactly how both tiers function and how to choose the right one for your network.

1. RetroMail Community Edition (Free)

The **RetroMail Community Edition** is published for free on Modrinth and SpigotMC. It is designed to help small, single-server setups and network hubs verify player emails securely without upfront costs.

  • ⚙️ Standalone Core Verification: Includes full double-opt-in SMTP email verification. Players type their email in-game, receive an activation code in their inbox, and unlock reward commands upon verification.
  • 🔗 Multi-Server Network Sync: Yes! Unlike other premium plugins, multi-server network synchronization via BungeeCord and Velocity is **100% free**. The plugin code itself has no restrictions preventing Bungee/Velocity channel sync or local MySQL coordination on the free version.
  • 💾 Local Storage & Config: Verification records and player data are stored locally in SQLite or MySQL databases, and configurations are managed through standard local `.yml` files.
  • 👥 Community Support: Support is handled through community Discord channels and public GitHub issue boards.

The Community Edition is fully functional, has no time limits, and will remain free for server owners forever.

2. RetroMail Commercial License (Paid)

The **RetroMail Commercial License** is built specifically for commercial networks and server owners who want full automation, visual mailing tools, clean white-labeled branding, and direct priority support.

Watermark Removal

Commercial licenses remove the default "Mail System by AJA_RETRO" watermark appended at the bottom of verification emails, allowing you to present a 100% clean and white-labeled brand to your players.

Full-Stack Web Dashboard

Access to the responsive administration web portal (front-end). Admins can view real-time player verification analytics, customize newsletter themes visually in a browser editor, manage licenses, and send mass emails using a secure web composer interface.

  • 🔑 Automated License Verification: Paid installations link securely to our centralized licensing server using HMAC-SHA256 signature verification.
  • 📞 Dedicated Developer Retainer: Commercial clients receive direct developer support with guaranteed SLA response times to handle custom patch requests, API integrations, and database migrations.

Conclusion

Our pricing model is built to scale *with* your server. As your player base grows and your setup transitions from a single server to a network cluster, you can transition from the free standalone tier to the commercial license to unlock clean white-labeling, web panels, and dedicated support.
